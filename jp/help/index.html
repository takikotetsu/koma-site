入れる

インストーラを実行します。プラグインもアプリも一度に入ります。

先にホストを終了してください。 Resolve / Premiere / After Effects / Flame が 起動しているとインストーラが止まります。開いたまま入れても、ホストは古い方を 掴んだままです。

入る場所:

OFX（Resolve、Flame）/Library/OFX/Plugins
Adobe（Premiere、After Effects）/Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore
アプリ/Applications

Resolve は Studio が必要です。 無償版は OFX プラグインを読み込みません。

使う

  • Resolve — エフェクト → OpenFX → Filter → KOMA
  • Premiere / After Effects — エフェクト → KOTETSU → KOMA
  • Flame — OFX → KOMA

グレーディングは KOMA の前段でしてください。KOMA は表示参照の Rec.709 で動きます。 log 素材のときは Input Colorspace でその形式を選ぶと、手前に変換が入ります。

色空間

KOMA は表示参照の Rec.709 で動きます。

入力出力
Rec.709 / sRGBそのまま（変換しません）
Log / LinearRec.709 に変換して返します
Bypass何もしません

log を選んだときだけ片道です。フィルム段が「シーン参照 → 表示参照」そのものなので、 S-Log3 に戻る道はありません。

HDR（PQ / HLG）と ACES には対応していません。 P3 も選べません。 これらの素材をそのまま入れると、絵は出ますがエラーは出ず、色は正しくありません。

更新する

新しいインストーラを、同じ手順で入れ直すだけです。 設定もライセンスも プロジェクトも残ります。

パネルの上に KOMA 1.2.1 — 1.3 が出ています と出たら、新しい版があります。 1日1回、サイトの版番号だけを見ています。ネットが無ければ何も出ません。

ライセンス

入れるところはアプリの環境設定だけです。 プラグインのパネルからは入れられ ません（OFX にその仕組みが無いため）。1本入れれば、プラグインもアプリも 有効になります。

  • 同時に2台まで。 機材を入れ替えるときは、片方を解除してからもう1台で

有効にします。解除は Polar のアカウントページ、またはアプリの環境設定から

  • 認証はオンラインで1回。 そのあとはネットが無くてもレンダリングできます。

ネットがあるときだけ1日に一度確認しますが、繋がらないことで止まることは ありません

  • ライセンスを入れるまでは、全機能が使えて出力に透かしが乗ります。期限はありません

うまくいかないとき

プラグインが出ない ホストを再起動してください。それでも出ないなら、Resolve が Studio かどうかを 確認してください。無償版は OFX に対応していません。

インストーラがエラーで止まる ホストが起動しています。Premiere や After Effects は、閉じたつもりでも バックグラウンドに残ることがあります。

After Effects で「重複してインストールされています」と出る 古いコピーが残っています。ユーザー領域 （~/Library/Application Support/Adobe/…/MediaCore）に KOMA.plugin があれば 削除してください。正しい場所は /Library の側だけです。

透かしが消えない アプリの環境設定でライセンスを入れてから、ホストを再起動してください。 プラグインは起動時にライセンスを読みます。

4K が重い MTF / Acutance を切ると UHD で約 9.5 ms 戻ります。編集中は切って、 書き出しで戻す使い方ができます。ノートパソコンでは電源に繋いでください — 電池残量が少ないと、CPU 側が絞られて間に合わなくなることがあります。

After Effects が遅い After Effects では現在 CPU で描いています。Premiere と Resolve は GPU です。

消す

アプリのメニューから KOMA → Uninstall KOMA… を選びます。 ライセンスと設定は残ります。

連絡先

support.koma@kotetsu.work

経年

コントロール範囲既定
クロスオーバーを有効化オフ量の既定が 0 なので、スイッチも既定オフです。オンなのに何もしていないスイッチは、絵の側に説明がありません。
クロスオーバー-1 – 103層の特性曲線が平行でないと、ニュートラル軸が曲がり、階調の両端が逆方向へ振れます。合わないプリント材に焼いたネガ、クロス現像、そしてほとんどの経年フィルムで起きること。1つの原因が両端を動かすので、コントロールも1本です — 暗部と明部を別々に振れるものは、スプリットトーンであってこれではありません。
クロスオーバーの軸0 – 3600どちら向きか。0 は暗部が青、ハイライトが黄。青感層が最上層なので、経年はこの向きに進みます。
色斑（モトル）オフ同じノイズの低周波側です。粒状性は 48µm の開口で測りますが、スペクトルはその下まで伸びていて、そこでも3層は無相関のまま。だから輝度の粒ではなく色の斑として見えます。現像ムラと塗布ムラも同じ帯に入ります。
色斑の量0 – 202つの粒の世代と違い、銘柄の粒状性には比例しません。
色斑の大きさ0.25 – 41斑ひとつの大きさ。1 で画面の約 1/20 です。
色斑を静止させるオフフィルムは動きます。1コマ1コマが別のフィルムなので、斑も毎フレーム 引き直されます。チェックを入れると1枚の場で静止します — 80px の斑が毎秒24回入れ替わると、質感ではなく「沸いている」ように 見えることがあるので。
